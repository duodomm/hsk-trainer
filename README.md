# HSK Trainer

Тренер китайского языка для уровней HSK 1 и HSK 2.

- 300 слов HSK 1 с 15 примерами каждое
- 200 слов HSK 2
- Переключатели видимости (иероглифы, пиньинь, перевод)
- Анимация порядка черт и quiz-режим (тестово на нескольких иероглифах)
- Аудио произношения (Web Speech API, тестовые режимы)

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:8080

Собран на React + Vite + TanStack Router + Tailwind CSS + Zustand + hanzi-writer.
